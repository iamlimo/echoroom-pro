
  # EchoRoom v1

  This is a code bundle for EchoRoom v1.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Content publishing

  For blog publishing with Sanity, see [docs/sanity-blog-posting.md](docs/sanity-blog-posting.md).

  For YouTube playlist sync in the Studio page, create a `.env` file based on `.env.example` and set `VITE_YOUTUBE_API_KEY` and either `VITE_YOUTUBE_CHANNEL_ID` or `VITE_YOUTUBE_PLAYLIST_ID`.
